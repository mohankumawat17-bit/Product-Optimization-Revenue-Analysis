# Coffee Product Optimization & Revenue Analysis

## Project Overview
This project analyzes coffee shop transaction data to identify top-performing products, revenue contribution, and business insights.

## Tools Used
- Python (Pandas)
- Streamlit
- Plotly

## Key Insights
- Coffee and Tea contribute around 66% of total revenue
- Premium products generate higher revenue
- Some products have high sales but low revenue
- Low-performing categories contribute very little

## Features
- Interactive dashboard
- Category filter
- Store location filter
- Top products visualization
- Sales vs Revenue analysis

## How to Run
1. Install dependencies:
   python -m pip install -r requirements.txt

2. Run the app:
   python -m streamlit run app.py
